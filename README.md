## 🎯 项目介绍

&emsp;&emsp; 2025 年年底，我偶然接触到了 Agent。研究了一下之后觉得：这东西好像还挺有意思。于是就这么稀里糊涂地开始自学了。
但我这个人自控力比较一般，如果没有一个地方记录学习进度，很容易学着学着就开始拖延。所以干脆建了这个仓库，一边学习，一边把自己琢磨的学习路线、学过的东西都记录下来。
写着写着又发现，原来还有不少人也想进入 Agent 相关的行业。其中有已经会开发的，也有纯小白，甚至可能连一行代码都看不懂。
既然都已经写了，那干脆就把这些笔记慢慢整理成一套教程好了。
这个教程会尽量从零开始讲。我会默认你对 Agent、LLM、API 这些东西都不熟，很多代码也会尽可能解释清楚，希望即使是以前没有写过代码的人，也能大概知道每一行到底在干什么。
当然，完全零基础直接冲进来可能还是会有一点痛苦。所以在正式开始之前，我还是建议先花一两个星期学一下Python，把类、对象、变量、判断、循环、函数、列表、字典、错误捕获这些最基础的语法过一遍。不用学得特别深，至少看到代码的时候不会觉得像在看天书就行。
我自己也还在学习，所以这里不会是什么“大神从入门到精通”的教程，更像是一个普通人一边学Agent，一边把一路上弄明白的东西整理出来。
如果它刚好也能帮你学到一些东西，那这个仓库就算没有白建。

就这样，希望可以帮到你。

### ✨ 你将收获什么？

- 🔍 <strong>从零开始的学习路线</strong> 如果觉得无从下手不妨一试
- 🏗️ <strong>亲手实现</strong> 从最简单的问答到可运行的智能体
- 🛠️ <strong>搭建属于你的框架</strong> 基于 Openai 原生 API 从零构建一个自己的智能体框架
- ⚙️ <strong>掌握高级技能</strong> 一步步实现上下文工程、Memory、协议、评估等系统性技术
- 🚀 <strong>驱动真实案例</strong> 实战开发智能旅行助手、赛博小镇等综合项目
